# RPG 成长基线

这份文件是 RPG 与送礼联动链路的保底硬约束。

以后继续调签到、打怪、组队、世界 BOSS、送礼回流时，先看这里，再动数值。
如果实际配置和这份基线冲突，默认以这份基线为目标。

## 设计前提

- 核心用户不是最活跃的那批人，而是“手里有积分、暂时没人送礼、也不一定有人组队”的普通群友。
- RPG 必须是一条可独立成立的轻量成长线，而不是只给社交活跃玩家加速的附属系统。
- 送礼仍然是主社交线；RPG 可以挤占一部分积分消耗，但不能把送礼系统的存在感吃掉。
- 签到必须保留基本激励感；经验可以轻，但不应该轻到让人感觉“签了跟没签一样”。

## 单人保底合同

适用对象：

- 每天签到
- 主要打单人 `今日打怪`
- 不依赖组队
- 不依赖世界 BOSS
- 不把“有人送礼 / 有人陪玩”当作前提

目标线：

| 周期 | 单人保底等级 | 体感目标 |
|---|---:|---|
| 30 天 | Lv5-Lv6 | 明显变强，但仍在前中期 |
| 90 天 | Lv10-Lv13 | 进入稳定中段，开始接触更难怪 |
| 180 天 | Lv16-Lv20 | 接近成熟期，但不应完全毕业 |

约束说明：

- 单人玩家不能因为没人组队，就明显落后到“玩不下去”。
- 单人线允许慢，但不允许长期停滞。
- 高活跃社交玩家可以更快，但整体收益建议控制在单人线的 `1.2x-1.5x`。

## 怪物投放基线

怪物线按“半年内逐段推进”设计，不追求两个月内把主怪池全见完。

| 阶段 | 主体怪物 |
|---|---|
| 0-30 天 | 史莱姆 / 泥怪 / 哥布林 / 野狼 |
| 30-60 天 | 座狼 / 骸骨兵 / 食人魔 |
| 60-120 天 | 魔铠兵 / 石像鬼 |
| 120-180 天 | 双足飞龙 / 龙 / 风暴狮鹫 / 魔化奇美拉 |

Lv16 以后的常规遭遇按三等级一档继续推进：

| 等级 | 新进入常规池的怪物 | 基础战力需求 | 经验修正 |
|---|---|---:|---:|
| Lv16-18 | 风暴狮鹫 | 106 | +3% |
| Lv19-21 | 魔化奇美拉 | 120 | +5% |
| Lv22-24 | 深渊骑士 | 134 | +7% |
| Lv25-27 | 冰霜巨人 | 149 | +9% |
| Lv28-30 | 远古巨龙 | 164 | +12% |

落地要求：

- `龙` 不能在前中期就进入常规遭遇池。
- `双足飞龙` 应该属于明显后段的怪物，而不是一个月左右就频繁见到。
- 调整怪物节奏时，优先改 `combat.encounter_brackets`，不优先抬 `monsters[*].power_req`。
- 新增怪物默认不应回填旧分段；通过名称权重只在目标等级段显式放出，避免扩池后改变低等级玩家的抽怪概率。
- 继续扩展 Lv30 以上内容时，保留最后一个 `max_level=null` 作为安全回退，并在它之前追加有限等级分段。

## 送礼经济基线

单人玩家也必须保有稳定参与送礼的能力。

建议目标：

- 单人玩家每周至少能稳定送出 `3-5` 次 `100-200` 档礼物。
- `270+` 档礼物应当有一定积攒感。
- `819 / 1112` 档礼物应保留明显仪式感，不应因 RPG 回流而变成日常消耗。

## 调参优先级

当成长线跑得过快时，按这个顺序处理：

1. 先压 `签到经验`
2. 再改 `怪物遭遇分段`
3. 还不够，再看 `打怪经验 / 等级曲线`
4. 最后才动 `组队 / 世界 BOSS` 奖励

原因：

- 签到应该是背景推进，不该成为主要升级来源。
- 怪物分段决定“这段时间在玩什么”，属于体验节奏。
- 打怪经验和等级曲线会直接影响长期成长度，改动更重。
- 组队和世界 BOSS 更适合做趣味与社交补偿，不适合作为单人线的补丁。

## 维护规则

- 以后如果 README、维护文档、配置注释和这里冲突，以这里为准。
- 每次做 RPG 大改前，先确认这 4 件事：
  - 单人 30 / 90 / 180 天等级是否还落在目标区间附近
  - 高阶怪是否仍然被压在后段
  - 单人玩家是否仍有送礼参与能力
  - 社交玩法是否只是“更有趣”，而不是“强者更强”

## 可执行检查

运行以下命令会复现“连续签到 + 每天一次主动单刷”的 360 天长期成长，不计组队、世界 BOSS 和主动使用道具：

```powershell
py tools/simulate_rpg_growth.py --runs 1000
```

加上 `--strict` 后，只要 30 / 90 / 180 天中位等级偏离本文件目标，命令就会返回非零退出码；270/360 天用于观察 Lv30 内容覆盖与后续扩展窗口。
当前 300 条轨迹模拟约为 `Lv7 / Lv14 / Lv22 / Lv29 / Lv37`，Lv30 中位第 271 天到达（P10/P90 第 264/280 天）。实际单人线仍快于早期基线，但不直接提高等级曲线，避免已有玩家查询时出现掉级。
