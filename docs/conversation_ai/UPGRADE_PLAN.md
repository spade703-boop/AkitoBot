# 对话 AI 架构升级计划（总路线）

## 设计原则

- [x] 渐进式改造，不替换模型，不一次性重写主链路。
- [x] 保留现有人设、关系轴、时间感知、图片识别、记忆和 RPG 等既有功能。
- [x] 先解决上下文选择和记忆质量，再扩展工具编排；所有新能力都有旧路径或开关可回退。
- [x] 用户输入、网页结果和临时状态不能绕过系统规则；内部状态只保留短标签或摘要，不要求模型输出完整思维链。
- [ ] 所有质量门槛均有离线样例、线上 trace 和必要的人工复核，且在样本不足时不作放量结论。

## M0：基线与数据契约（已完成）

- [x] 定义统一的回合、上下文块、工具结果和输出信封类型。
- [x] 建立 68 条基线评测集，剧情回忆样例 12 条均绑定原作证据；剧情证据按事实归因、关系态度、情绪方向、自然度和臆造分别评估，不做逐字匹配。
- [x] 每轮记录 request id、意图、上下文来源、工具调用、耗时、Token、重试和实验臂；trace 不保存用户原文或回复正文。
- [x] 提供评测集校验、离线回放、线上 trace 聚合和按 surface/实验臂拆分的报告。

当前基线与复现命令见 [`baseline/M0_BASELINE.md`](baseline/M0_BASELINE.md)。该报告中的回复数和 AI 裁判分数仍为待采集，不将“评测集校验通过”当作回复质量通过。

## M1：上下文编排器

- [x] 归一化 `ContextBlock` 元数据，估算 Token，并按优先级、来源、时效和成本进行预算裁剪。
- [x] 主对话、自动回复和群印象统一走 Context Orchestrator；shadow 阶段只记录来源和估算，不写入上下文原文。
- [x] 支持 `control`/`m1`/`m2`/`combined` 实验臂及旧路径回退；M1 回归和预算测试通过。
- [ ] 用线上 trace 对比新旧选择结果，确认关系和剧情信息没有被误裁剪。
- [ ] 将旧历史兼容读取为原生 `user/assistant` 结构，并保留旧 JSON 格式。
- [ ] 将旧对话压缩为摘要 + 最近消息，逐步引入 `recent_turns` 与 `conversation_summary`，不直接丢弃全部历史。

## M2：分层记忆（通用部分）

- [x] 事件记忆以带来源/证据的只读资产接入，并在低置信度、模糊问题或无充分证据时返回 `no_hit`。
- [ ] 保留短期 `recent_turns`，新增旧对话 `conversation_summary`。
- [ ] 将 `long_term_facts` 升级为带置信度、来源、最近使用时间和 TTL 的结构化事实。
- [ ] 将记忆提取从正常回复拆出，降低对 `[[记下: ...]]` 的强依赖。
- [ ] 增加事实去重、冲突检测、过期清理、用户确认，以及旧版 `akito_memories.json` 的兼容迁移。

剧情事件记忆（事件化、导入、覆盖和 Hybrid）由 [`event_memory/REFACTOR_PLAN.md`](event_memory/REFACTOR_PLAN.md) 唯一维护；当前 826 条事件、44 条安全评测和覆盖数字以该计划及其生成报告为准。

## 跨表面与自动回复

统一 trace、shadow 评估、离线回放和人工复核由 [`auto_reply/PLAN.md`](auto_reply/PLAN.md) 维护。总路线只保留依赖关系：

- 主对话、自动回复、群印象共享角色关系事实和事件检索，但各自保留触发、静默、材料分析和输出约束。
- 三类 surface 的离线回放通过后，才能用线上分面指标讨论放量。
- 当前灰度报告是单臂观察时，只能说明稳定性，不能宣称新版优于旧版。

## M3：任务路由与工具编排

核心路由、带来源工具结果、有界循环和灰度开关已经落地；详细任务、测试矩阵和上线步骤只在 [`tooling/PLAN.md`](tooling/PLAN.md) 维护。当前默认 `off`，完成失败路径验收和对照观察后再扩大 canary。

## M4：输出质量、安全与灰度收尾

M4 仍未完成。JSON 修复/重试、语义重复与来源约束、信任边界、限流熔断、模型降级和压力测试统一记录在 [`tooling/PLAN.md`](tooling/PLAN.md)；总路线只保留“保留旧路径和一键回退”这一已完成前提。

- [x] 保留灰度开关、旧路径回退和一键关闭新编排器能力。

## 总体验收门槛

1. 现有功能和测试不回归，关键对话场景的事实归因、人物关系和时间连续性不下降。
2. 上下文 Token 可控；长对话有摘要/最近消息策略，不无限膨胀。
3. 长期记忆可追溯、可删除、可过期、可处理冲突；事件记忆能按事件召回并展开必要证据。
4. 搜索/工具失败可以自然降级，且不会覆盖角色设定或系统规则。
5. 新旧路径可切换；完成离线评测、人工复核和必要的对照后才扩大灰度。
