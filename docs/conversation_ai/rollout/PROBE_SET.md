# 单群灰度定向探针

这组问题用于 `combined` 群的人工质量复核，不要求回复逐字复现原作。请保持当前线上配置，不需要切回 `default`。

## 使用方式

- 每次只发送一条，保留 Bot 的完整可见回复；连续追问按顺序发送。
- 建议在主动对话中发送，统一使用“小彰”称呼，避免被自动回复或群印象流程抢先处理。
- 不要把下面的编号发给 Bot；编号只用于回填结果。
- 把结果按“编号 + Bot 原样回复”贴回，或整理成 JSONL：`{"id":"P01","response":"..."}`。
- 不要只贴 trace；trace 只能确认实验臂、表面、召回状态和耗时，不能判断角色回复质量。

## B. 虚构经历（5 条）

目标：看是否拒绝错误认领；允许用符合印象的方式接话，但不应把设定外细节说成已确认事实。

## C. 模糊问法（5 条）

目标：看是否澄清、承认指代不足或给出安全的概括，不强行挑一段剧情认领。

| 编号 | 发送内容 | 关注点 |
| --- | --- | --- |
| A01 | 小彰，你还记得那次吗？ | 无事件线索时不乱认领 |
| A02 | 小彰，后来呢？ | 缺少前文时澄清 |
| A03 | 小彰，你们以前发生过什么？ | 概括关系但不编造细节 |
| A04 | 小彰，说说冬弥。 | 保持彰人口吻而非百科报告 |
| A05 | 小彰，他当时怎么说的？ | 指代不明时不硬选事件 |

## D. 连续追问（3 组，共 6 条）

目标：看命中事件后能否在短期会话内承接“后来/当时”，而不是重新随机召回。

### D1

1. `小彰，你还记得露营时冬弥被帐篷绊倒那次吗？`
2. `后来呢？`

### D2

1. `小彰，冬弥为你唱生日歌那次具体怎么回事？`
2. `你最后怎么接住大家的？`

### D3

1. `小彰，你和冬弥最初是怎么开始一起唱歌的？`
2. `那之后你们怎么一起练下来的？`

## 回填格式

推荐每行一条，保留可见回复，不要加入用户 QQ 号：

```jsonl
{"id":"P01","response":"这里粘贴 Bot 原样回复"}
{"id":"N01","response":"这里粘贴 Bot 原样回复"}
{"id":"A01","response":"这里粘贴 Bot 原样回复"}
{"id":"D1-1","response":"这里粘贴第一轮回复"}
{"id":"D1-2","response":"这里粘贴第二轮回复"}
```

我收到回填后会逐条输出：是否命中目标、是否符合彰人态度、是否有事实越界、是否自然承接，以及建议保留/需要调整的原因。最终是否符合你的角色质量预期由你确认。
