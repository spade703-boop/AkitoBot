# 工具编排与输出安全计划

> 最后核对：2026-09-01。本文是联网工具、任务路由和输出安全的唯一计划入口；总路线见 [`../UPGRADE_PLAN.md`](../UPGRADE_PLAN.md)。

## 当前状态

核心 M3 链路已经实现，但生产默认仍为 `off`，且完整验收集尚未通过。M4 的质量与安全护栏仍是后续工作。

## 已完成能力

- [x] 明确区分角色事实与现实世界事实；角色资料优先本地，联网结果不能覆盖角色设定。
- [x] 明确联网请求才进入搜索；闲聊、角色互动和图片请求不误触搜索。
- [x] 搜索结果以带来源的工具消息进入二次生成，不再作为无来源旁白。
- [x] 工具参数长度、调用次数、重复查询和剩余时间均受限；无结果、超时和异常统一走本地回答、澄清或降级文案。
- [x] `shadow` 只记录路由而不改变用户收到的旧链路回复；`canary`/`on` 才启用新循环。

M3 `shadow` 的语义是“运行但不生效”：对明确需要联网的请求可执行一次有界新循环并记录匿名 trace，结果不注入最终提示词，随后仍走旧链路回复；普通请求不主动触发工具。只有 `canary` 才对指定群让新循环结果生效，`on` 才表示在已通过门槛的覆盖范围内持续启用。

## 待完成任务

### M3 验收与上线

- [ ] 扩充路由测试：闲聊、角色问题、本地知识、明确联网、图片、记忆、管理命令和多步任务的边界与低置信度情况。
- [ ] 覆盖 0、1、3 次工具调用，以及重复查询、参数非法、单次超时、总预算耗尽、无结果、过期和 API 错误。
- [ ] 验证网页/工具内容只作为不可信输入，不能改写系统规则、角色设定或临时状态。
- [ ] 先在 `shadow` 观察，再对照 `default` 做 `canary`；每次只扩大一个群组，异常时关闭对应开关即可回到旧路径。
- [ ] 记录工具成功率、超时/降级率、来源完整性、Token、延迟和用户可见错误，样本不足时不作放量结论。

### M4 质量与安全

- [ ] 增加 JSON 自动修复和有限次数重试，修复失败时保持可发送的降级结果。
- [ ] 增加语义级重复检测、不同角度重生成和关键关系/事实来源一致性检查。
- [ ] 将 `inner_os` 限制为短内部状态，不保存或展示完整思维链。
- [ ] 为用户输入、网页结果和临时植入状态建立信任边界，并明确不确定、无结果和过期状态。
- [ ] 增加超时、限流、熔断、模型降级和错误恢复；完成压力测试和全量回归。

## 验收门槛

1. 工具调用永不超过次数/时间预算，且失败不会阻塞正常聊天、图片、管理和 RPG 链路。
2. 现实搜索结果带来源和时效，不覆盖本地角色事实；低置信度请求会本地回答或澄清。
3. M3 离线测试和人工抽查通过后，才允许从 `canary` 扩大到 `on`。
4. M4 完成前保留旧路径和一键关闭开关。
